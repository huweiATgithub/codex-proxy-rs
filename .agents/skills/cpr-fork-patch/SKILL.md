# Fork 补丁

本技能约束 fork 补丁如何保持可移植性，与 [开发指南](../cpr-dev-guide/SKILL.md) 一起执行
[补丁维护指南](../../../docs/patch-guide.md) 负责分支、主题提交整理、tag、重放和发行操作，本技能不另设发布入口

## 开发与移植

- 先确定原始上游基线、补丁主题和所属模块合同，结合新上游调用关系检查语义；Git 无冲突不代表数据库或业务合同兼容
- 保留上游行为，把 fork 自有状态与上游状态的所有权分清；数据库扩展只新增或演进 fork 自有对象，不改变上游 schema 或改写已执行迁移
- 涉及 migration、SQL、持久化状态或数据库升级时，先读 [SQL 约束](references/sql.md)；无数据库变更的主题不加载该参考
- 具体功能的身份隔离、晚响应、删除与清理保证由所属 API 或架构合同说明，主题提交指向对应章节，不在本技能复制功能细节
- 如果继续移植必须改变主题目标、职责或合同，按维护指南的[根本性冲突流程](../../../docs/patch-guide.md#升级到下一个上游-tag)报告并等待维护者决定；已有明确决策只适用于其授权范围
