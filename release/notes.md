# v3.22.1

## 修复与改进

- 修复上游性能明细漏采：读取当前响应的关键路径计时，恢复引擎耗时与 API 开销，并校验响应归属，避免混入整轮累计时间
- 改进数据库迁移期间的启动反馈：迁移或等待迁移锁时，每 15 秒记录已等待时间；镜像与 Compose 的健康检查启动宽限期延长至 5 分钟
- 统一管理端重启、SIGTERM 与 SIGINT 的关闭流程，停止监听后结束剩余会话，保留后台观测写入与资源清理的收尾预算

## 升级事项

- 从 v3.22.0 升级没有新增数据库迁移；从更早版本升级仍会执行相应历史迁移
- 停止或重启会断开尚未完成的 HTTP、SSE 与 WebSocket 会话；`host.drain_timeout_seconds` 不再生效，后台收尾预算由 `host.worker_shutdown_timeout_seconds` 控制
- 现有 Compose 部署需同步新的健康检查配置并重建容器，才能应用 5 分钟的启动宽限期
- 新增采集的上游性能数据只影响升级后的请求，历史记录中的空缺不会自动补齐
