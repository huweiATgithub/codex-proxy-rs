# v3.23.1

## 修复与改进

- OpenAI Responses 的结构性前导事件保留到有效文本、推理、工具活动或终态再交付；有效输出前的 WebSocket 传输故障按现有预算进行同账号恢复，减少提前交付造成的空响应和恢复机会丢失
- WebSocket 观察到上游关闭或读取错误后立即标记连接失效，拦截已关闭连接上的发送，并跳过已取消的排队消息，减少无效上游请求；保留原始关闭原因和关闭前的静默时长
- 优化统计与用量查询的观测视图，恢复普通聚合的索引和并行查询规划，同时保留计时统计的计算复用，减少无关 JSON 投影开销
- 管理端更新共享 UI 组件，统一表单、弹窗、加载状态和操作反馈的接入

## 升级事项

- 新增数据库迁移 `0027_request_observation_projection.sql`，更新观测视图，保留字段顺序、类型、取值和只读属性，不重写历史请求数据
- 有效输出前的 WebSocket 传输恢复沿用 `stream_max_retries`，默认最多 5 次；尽力重试不保证上游只执行一次，精确连接续接仍受原连接和客户端恢复边界限制
- 前导事件缓冲不另设固定等待时限或累计体积上限，取消、请求截止时间和现有传输超时仍生效
