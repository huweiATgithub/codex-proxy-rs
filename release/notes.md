# v3.22.2

## 修复与改进

- 移除 OpenAI Responses 提交前缓存的 128 KiB 字节阈值，避免大段前导事件提前结束透明重试窗口；HTTP/SSE 与 WebSocket 均保留 2.5 秒宽限期及语义输出、终态等放行规则
- 完善 WebSocket 控制消息透传：中断及其他非创建文本消息原样发送到当前绑定的上游连接，响应结束后仍可转发控制消息与上游事件，不额外创建推理请求
- 完善 OpenAI 扩展字段和原文透传，保留推理强度的数字及扩展值、WebSocket 原始文本、业务元数据，以及 Images/Search 的业务请求头；避免未改写的心跳或未知内容因本地解析失败而被截断
- 诊断导出升级为 schemaVersion 4，补齐提交前缓存的释放原因、累计字节数与等待时间，便于区分实际输出和宽限期到期等提交原因
- 健康探测保留具体失败组件、原因及超时信息，持续相同故障避免重复记录；xAI 后台任务保留额度与模型目录同步的失败原因
- Codex 配置模板显式启用 V2 远程压缩，并补充 CC Switch 一键导入的配置边界说明

## 升级事项

- 从 v3.22.1 升级没有新增数据库迁移；从更早版本升级仍会执行相应历史迁移
- 使用 Codex 0.162.0 及以上版本时，可重新复制并合并配置模板以启用 V2 远程压缩；CC Switch 一键导入不包含该能力配置
- 本版为插件 `middleware v3`、`upstream_adapter v1` 的最后一个兼容正式版；插件作者应迁移至 `middleware v4`、`upstream_adapter v2`，以 `fast_mode` 三态替代 `disable_fast`
- 移除字节阈值不会放宽已经交付输出后的重放限制，上游错误仍需满足安全重试条件
